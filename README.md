## What it does

Studios lose millions because critical business signals are scattered across dozens of dashboards. By the time a human analyst spots a crisis, hours have passed.

**Studio Crisis Commander** changes that. A network of Gemini-powered autonomous agents continuously monitors entertainment telemetry in ClickHouse, detects anomalies the moment they emerge, investigates root causes, and recommends data-grounded recovery strategies within minutes.

### Example workflow

A trailer launches worldwide. ClickHouse detects sentiment dropping 28%, EU engagement collapsing, refunds spiking. The Investigation Agent queries regional breakdown and trailer variant performance via mcp-clickhouse. The Decision Agent recommends pausing Trailer A, promoting Trailer B, and shifting budget to Korea — every figure computed in SQL, none generated by the LLM. The Executive Report links every claim to its source query. The dashboard updates. Approval gate fires. Audit trail logged.

## Architecture

```
React Dashboard (Vite + Recharts + live agent trace)
        |
FastAPI Backend (Cloud Run, GCP us-east1)
        |
Four-Agent Pipeline (Google ADK + Gemini)
  Detection Agent  -->  Investigation Agent
  (pure SQL/EWMA)       (mcp-clickhouse MCP)
                              |
  Decision Agent  -->  Executive Report Agent
  (approval gates)     (query-sourced figures)
        |
mcp-clickhouse MCP server
        |
ClickHouse Cloud (GCP us-east1, 50M+ rows)
  box_office | streaming | trailer | marketing
  sentiment  | regional  | refunds | social
```

## Quickstart

### Prerequisites
- Python 3.11+, Node.js 18+
- Google Cloud project with Vertex AI API enabled
- ClickHouse Cloud account (GCP us-east1)

### Setup

```bash
git clone https://github.com/YOUR_USERNAME/studio-crisis-commander.git
cd studio-crisis-commander
cp .env.example .env   # fill in real values

cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python data/generator.py          # generate 50M+ row dataset
uvicorn main:app --reload         # run backend

cd ../frontend
npm install && npm run dev        # run frontend
```

### Deploy

```bash
gcloud run deploy studio-crisis-backend \
  --source backend/ --region us-east1 --allow-unauthenticated
```

## Agent design

**Detection Agent** — pure ClickHouse SQL. Window functions, z-scores, EWMA over rolling baselines. Zero LLM. Deterministic and sub-second at 50M+ row scale.

**Investigation Agent** — multi-query correlation via mcp-clickhouse MCP server. LLM narrates computed values, never generates numbers independently.

**Decision Agent** — governed autonomy with configurable approval thresholds. Auto-execute below a spend limit, require human sign-off above. Full audit trail.

**Executive Report Agent** — every figure links to its originating ClickHouse query. Fully traceable, no hallucinated specifics.
